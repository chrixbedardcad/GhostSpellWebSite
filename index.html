Clean install

Install in one line

Simple. Sharp. Done.

Open Terminal on macOS or Linux, or Command Prompt on Windows, then paste the command for your platform to install GhostSpell in seconds.

macOS / Linux 
curl -fsSL https://raw.githubusercontent.com/chrixbedardcad/GhostType/main/scripts/install.sh | bash
Windows 
powershell -c "irm https://raw.githubusercontent.com/chrixbedardcad/GhostType/main/scripts/install.ps1 | iex"

What’s the catch? Nothing.

GhostSpell exists because writing is hard for a lot of people, and help should not be locked behind subscriptions, ads, or bloated software.

It is built to be quiet, practical, and kind — especially for people who struggle with spelling, dyslexia, or writing in English as a second language.

Open source project

Built to help, not to squeeze people.

GhostSpell is an open source project. The creator is not chasing subscriptions or trying to turn writing help into a trap. This is something he wanted to exist, so he made it and shared it for everyone.

The goal is simple: make writing easier for people who need it, keep it clean, and keep it available.
