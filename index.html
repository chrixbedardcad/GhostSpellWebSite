How it works

🖱️

Select your text

Highlight the messy sentence, rough message, or half-baked AI prompt you want to improve.

⌨️

Press Ctrl+G

GhostSpell stays out of the way until you ask for help, then fixes the text right where you are writing.

✨

Send cleaner words

Use the improved text for email, Slack, school, work, social posts, or better prompts for your AI of choice.

AI prompt cleanup
Rough prompt

write a polite mail to my boss say i finish the task but im not sure if english is good and ask if he want change

Ctrl+G →
Cleaner prompt

Write a polite email to my manager saying I finished the task, that I would appreciate feedback, and asking whether any changes are needed.

Better prompt in, better result out. GhostSpell helps your message land better whether the next reader is a person or a machine.

Install GhostSpell

Choose the command for your platform, paste it into your terminal, and GhostSpell will install in a few seconds.

macOS / Linux 
curl -fsSL https://raw.githubusercontent.com/chrixbedardcad/GhostSpell/main/scripts/install.sh | bash
Windows 
powershell -c "irm https://raw.githubusercontent.com/chrixbedardcad/GhostSpell/main/scripts/install.ps1 | iex"

GhostSpell should feel easy first. You have four clear options: the built-in Local-AI default, Ollama on your own machine, account login for supported cloud providers, or raw API keys for full control.

👻

Local-AI (default)

GhostSpell includes a default AI setup out of the box. It handles around 70–80% of common writing fixes for free, with no extra setup, and is the easiest place to start.

👻

Ollama (local)

Want a more private local setup on your own machine? Use Ollama. It stays local and free, while giving you more flexibility over which model you run.

🔐

OAuth / account login

Prefer a smoother cloud setup? Sign in with a supported provider account and connect without manually juggling raw keys.

🗝️

API keys

Use API keys for stronger models, faster responses, or more advanced setups. Paid cloud models usually give better results and speed when you want more than the free default.

Start with the built-in Local-AI if you just want help fast and free. Move to Ollama for local control, or use cloud providers when you want better quality, more speed, or more model choice.
