Use the AI stack you already like. GhostSpell supports three simple connection styles so it can fit both easy setups and advanced ones.

1. Default local Ollama: use the free local Ollama setup for a simple default experience that works out of the box on your own machine.
2. OAuth / account login: sign in with a supported provider account when you want a simple cloud connection without managing raw keys yourself.
3. API keys: use advanced API key connections when you want more control, custom providers, or higher-end models.

That means GhostSpell can always work with the default Ollama install, while still letting you move up to login-based or API-based setups whenever you want.
